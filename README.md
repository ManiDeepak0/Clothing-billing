# Clothing Billing System

A web-based billing application designed to simplify product selection, shopping cart management, bill generation, and daily billing summaries.

## Features

- Product and brand listing
- Search products by brand
- Shopping cart and quantity management
- Bill calculation with GST
- Bill history and daily summary
- Payment method selection
- Bill sharing functionality
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open `shopping_cart.html` in a web browser.
3. Click the welcome screen to continue.
4. Use the demo login displayed in the application.

## Note

This is a demonstration project. The client-side login is not secure for production use. Billing history is stored in browser Local Storage.
